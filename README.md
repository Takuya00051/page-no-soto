# 京都文学マップ

京都を舞台にした小説の登場スポットを地図で巡る、閲覧専用のサイト。
サーバーもビルドも不要な静的サイトで、**`data.js` を編集するだけ**で作品や場所を追加できます。

## 使い方（閲覧）

`index.html` をブラウザで開くか、静的ホスティング（Vercel / GitHub Pages など）に置くだけで動きます。

- サイドバーで作品にチェックを入れると、その作品の登場スポットにピンが立つ
- ピンをクリックすると、その場所で小説の中で何が起きたかが表示される
- 複数作品にチェックを入れると、共有されている場所のピンが**色分けされた扇形**になり、「◯作品がリンクする場所」と表示される
- 選択状態は URL のハッシュ（例 `#yoru-mijika,yojohan`）に反映されるので、その状態のままブックマーク・共有できる

## データの更新方法

編集するのは `data.js` の 2 箇所だけです。

### 1. 場所を追加する（`SPOTS`）

場所は作品をまたいで共有されるので、ここで一元管理します。

```js
const SPOTS = {
  "tetsugaku-no-michi": {                 // 英数字のID（作品側から参照する）
    name: "哲学の道",                      // 表示名
    lat: 35.0271,                          // 緯度
    lng: 135.7944,                         // 経度
    note: "銀閣寺から南禅寺へ続く散歩道。",  // 場所の説明（省略可）
  },
  // ...
};
```

緯度・経度は Google マップで場所を右クリックすると表示される数値をコピーすればOK。

### 2. 作品・シーンを追加する（`WORKS`）

```js
const WORKS = [
  {
    id: "sabaku",                    // 英数字のID（URL共有に使われる）
    title: "作品名",
    author: "著者名",
    color: "#7a5ca8",                // この作品のピン・表示色
    scenes: [
      {
        spot: "tetsugaku-no-michi",  // SPOTS のID
        text: "この場所で小説の中で何が起きたかを書く。",
      },
    ],
  },
  // ...
];
```

- 既存の場所に別の作品のシーンを足したいときは、同じ `spot` ID を参照するだけ。自動的に「リンクする場所」として扇形ピンになります。
- `SPOTS` に存在しない ID を書くとそのシーンはスキップされ、ブラウザのコンソールに警告が出ます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `data.js` | **作品・場所データ（更新するのはここだけ）** |
| `app.js` | 地図・ピン・ポップアップの表示ロジック |
| `style.css` | デザイン |

地図は [Leaflet](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/) を使用（APIキー不要・無料）。
