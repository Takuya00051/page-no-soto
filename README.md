# 京都文学マップ

京都を舞台にした小説の登場スポットを地図で巡る、閲覧専用のサイト。
静的サイト（Leaflet + OpenStreetMap、APIキー不要）で、データは `data.json` 一つに入っています。

公開URL: https://takuya00051.github.io/ClaudecodeTest2/kyoto-literary-map/

## 使い方（閲覧）

- サイドバーで作品にチェックを入れると、その作品の登場スポットにピンが立つ
- ピンをクリックすると、その場所で小説の中で何が起きたかが表示される
- 複数作品にチェックを入れると、共有されている場所のピンが作品色の扇形になる
- 選択状態は URL のハッシュ（例 `#yoru-mijika,yojohan`）に反映されるので、その状態のまま共有できる

## データの更新方法①: サイト上で編集（推奨）

地図左下の「✎ 編集」ボタンから、フォームでシーン・場所・作品を追加編集できます。

- 作品・場所はプルダウンから選択。「＋ 新しい〜」を選ぶと入力欄が出る
- 新しい場所は**地図をクリックすると座標が自動入力**される
- 既存の作品×場所の組み合わせを選ぶと本文が読み込まれ、更新・削除ができる
- 既存の場所を選ぶと「📍 ピンの位置を打ち直す」で座標を修正できる（地図クリック→この位置で保存）
- 「下書き」にチェックすると、その作品はトークンを設定したブラウザ（＝自分）にだけ「下書き」バッジ付きで表示され、他の閲覧者には出ない（※ data.json 自体は公開リポジトリにあるので、完全な秘匿ではない点だけ注意）
- 京都以外（奈良・滋賀・大阪・東京など）のスポットも登録可能。初期表示は京都のまま。サイドバー下の「表示中のピンに画面を合わせる」で選択中の作品のピン全体へ移動できる

保存先は2通り:

1. **GitHub トークンを設定した場合（推奨）**: 保存すると `data.json` が GitHub に直接コミットされ、数分でサイトに反映される。
   - トークンの作り方: GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate new token。対象リポジトリを `ClaudecodeTest2` のみに絞り、Repository permissions の **Contents: Read and write** だけを付与する
   - 編集パネル内「保存先の設定」にトークンを貼って保存（このブラウザの localStorage にのみ保存される。共用PCでは設定しないこと）
2. **トークン未設定の場合**: `data.json` がダウンロードされるので、リポジトリの `kyoto-literary-map/data.json` と差し替えて push する

閲覧者にも編集ボタンは見えますが、トークンがなければリポジトリには何も書き込めません。

## データの更新方法②: data.json を直接編集

`data.json` は次の構造です。

```json
{
  "spots": {
    "tetsugaku-no-michi": {
      "name": "哲学の道",
      "kana": "てつがくのみち",
      "lat": 35.0271,
      "lng": 135.7944,
      "note": "銀閣寺から南禅寺へ続く散歩道。"
    }
  },
  "works": [
    {
      "id": "sabaku",
      "title": "作品名",
      "author": "著者名",
      "color": "#7a5ca8",
      "scenes": [
        {
          "spot": "tetsugaku-no-michi",
          "text": "この場所で何が起きたかを書く。",
          "quote": "該当箇所の短い引用（省略可）"
        }
      ]
    }
  ]
}
```

- 場所は `spots` で一元管理し、作品の `scenes` から ID で参照する。複数の作品が同じ `spot` を参照すると自動的に扇形ピンになる
- 作品や場所を丸ごと削除・改名したいときはこちらの方法で
- 緯度・経度は Google マップで右クリックすると表示される数値をコピーすればよい
- `quote` は本文からの引用。公開サイトなので、引用は短い範囲にとどめること（出典は作品名として表示される）

## スポット写真について

ポップアップの写真は、スポットの座標周辺の Wikimedia Commons 画像を自動検索して表示しています（出典リンク付き）。
自動で出てくる写真を差し替えたい場合は、`spots` の該当エントリに `"photo": "画像URL"` を追加すると、そちらが優先されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `data.json` | **作品・場所データ** |
| `app.js` | 地図・ピン・ポップアップの表示ロジック |
| `editor.js` | サイト上の編集機能（GitHub コミット／ダウンロード） |
| `style.css` | デザイン |

公開ページは GitHub の main ブランチ上の `data.json` を直接読むため、編集のコミット後すぐ（リロードで）反映されます。GitHub Pages の再ビルドを待つ必要はありません。
